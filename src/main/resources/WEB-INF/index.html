🚀 Java 21 HTTP Server (Virtual Threads)

A lightweight, blazing-fast HTTP server built with modern Java and virtual threads.

🔧 How to Start


ConnectionHandler connectionHandler =
    new ConnectionHandler.ConnectionHandlerBuilder()
        .setPort(8080)
        .setMaxConcurrentTask(1000)
        .setTimeOutMilliSec(500)
        .build();

connectionHandler.start();

Note: Run with --enable-preview flag (Java 21+).

🛠️ Configure Routes

Define all your HTTP routes in resources/http/request-mapper.yaml


http:
  version: 1.1
  routes:
    GET:
      - endpoint: ## /endpoint
        type: ## file or controller
        path: "/WEB-INF"
      - endpoint: "/css/style.css"
        type: file
        path: ## filepath or classpath
    POST:
      - endpoint: ## /endpoint
        type: ## file or controller
        path: ## filepath or classpath
    PUT:
      - endpoint: ## /endpoint
        type: ## file or controller
        path: ## filepath or classpath

📁 Static File Support

Serve static files from your configured directories via GET,POST,PUT,DELETE endpoints.
